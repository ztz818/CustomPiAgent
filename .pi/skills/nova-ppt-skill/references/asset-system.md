# 素材系统

Nova 的素材不是“可选装饰”，而是页面表达所使用的不同语言。先判断这页要表达的是结构、关系、证据、品牌还是状态，再选对应素材。

## 先看什么

- 先看 `templates/style-catalog.json`：决定全篇颜色、字体、圆角、阴影和默认图标家族。
- 再看 `templates/layout-catalog.json`：决定标题区、视觉区、卡片区、流程区、时间线区和结论区的几何骨架。
- 再看 `references/layout-patterns.md`：决定当前页面应该画成主张、三部分模型、流程、时间线、数据页还是决策页。
- 再看 `references/visual-system.md`：决定字体角色、颜色角色和形状语言的细节。
- 再看 `references/icon-system.md`：决定图标家族、图标尺寸、底形和图标与文字如何配合。
- 再看 `references/quality-gates.md`：决定什么情况必须返工。

## 素材类型

- `icons`：紧凑的语义符号，适合类别、步骤、状态、提醒、服务锚点。
- `pictures`：照片、产品图、截图和生成式插画，适合真实场景、产品证据、人物或空间。
- `native`：可编辑形状、线条、连接线、图表和表格，适合关系、流程、比例、比较和数据。
- `motifs`：属于全篇视觉身份的重复装饰几何，适合页眉、底带、角标和重复背景元素。

用户可能需要修改含义、数字、流程、层级或结论时，优先使用原生对象。内部结构无需修改、但需要传达真实证据时，使用图片。需要建立“看一眼就懂”的类别锚点时，使用图标。

## 什么时候用什么

- 讲“是什么”：用标题、短正文和图标。
- 讲“谁和谁的关系”：用连接线、分组底和并列模块。
- 讲“先后顺序”：用流程、箭头、编号和阶段标签。
- 讲“变化和推进”：用时间线、里程碑和不同权重的阶段块。
- 讲“数据和对比”：用表格、原生图表、数据条或指标卡。
- 讲“真实状态”：用图片或生成图，不要把场景硬改成图标。
- 讲“品牌身份”：用主题色、字体、页眉、页码和少量 motif，而不是堆装饰。

## 目录含义

`assets/` 不是素材仓库的堆放区，而是可被规则调用的表达资源。每个子目录有明确职责：

- `assets/icons/`：本地 SVG 图标库。按图标家族分目录，供统一风格的语义符号调用。
- `assets/icons/chunk-filled/`：更硬朗、结构感更强，适合技术、系统、深色发布或强调骨架。
- `assets/icons/tabler-filled/`：更圆润、服务感更强，适合医疗健康、服务设计、老板汇报。
- `assets/icons/tabler-outline/`：更轻、更适合高密度说明页和流程页。
- `assets/icons/phosphor-duotone/`：更柔和，有双色层次，适合可信、临床、照护类主题。
- `assets/icons/simple-icons/`：只放真实品牌标志，不作为通用图标库使用。
- `templates/style-catalog.json`：风格主档，告诉 agent 一整套演示应该采用哪种色板、字体和图标家族。
- `templates/layout-catalog.json`：版式骨架库，告诉 agent 各类页面的标准几何区块怎么摆。

## 内置图标家族

- `chunk-filled`：硬朗、紧凑、实心几何。用在技术、系统、深色、强调结构感的演示。
- `tabler-filled`：圆润、友好的实心图标。用在医疗、服务、护理、汇报类页面。
- `tabler-outline`：轻量线性图标。用在说明密度高、需要留白更多的页面。
- `phosphor-duotone`：带柔和层次的双色图标。用在需要温和可信感的页面。
- `simple-icons`：仅用于真实品牌标志。

一套演示只能选择一个通用图标家族。品牌标志不算通用家族切换。

## 图标如何参与版式

图标不是贴上去就完成了，必须进入页面结构：

- 独立图标：用于章节、状态、导航或单点强调。
- 图标 + 浅底圆/方底：用于类别锚点，常见于三部分模型和服务卡。
- 图标 + 编号 + 短标题：用于流程节点、时间线节点或步骤说明。
- 图标 + 连接线：用于表达动作流、服务闭环或用户旅程。
- 图标 + 数据：用于让指标更快被识别，但图标不能替代表格或图表。

图标尺寸通常控制在 18–72 pt 之间，具体取决于它是标签、卡片锚点还是章节主视觉。图标颜色优先继承演示稿强调色或文字色，除非该页明确需要状态色。

## 图片如何使用

受众需要检查真实人物、地点、产品、界面或状态时使用图片。事实检查重要时，避免昏暗、重度模糊和泛化库存图。

每张图片必须有明确裁切、版面角色、替代文本和足够分辨率。图片常用于封面主视觉、案例页、场景页和证据页。

## 自定义矢量

自定义 SVG 可放入 `assets/icons/custom/`，并以 `custom/<name>` 引用。保留 `viewBox`，移除脚本和外部引用；希望支持换色时使用 `currentColor`。

## 授权

内置图标保留各自原始库名。对外分发整个技能包前需要核对图标和品牌标志授权。演示稿不得声称独占第三方品牌标志。
